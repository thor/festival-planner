# Persistence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist festival data (Festival, Festival Series, Film, Programme Entry, Screening, Event, Venue, Route) in SQLite through SQLAlchemy 2 repositories and Alembic migrations, and ingest the Filmfrasor programme and the YAML venue/travel configuration into it, idempotently and with stable ids.

**Architecture:** Hexagonal, as in step 1. The domain gains timezone-aware times, Festival / Festival Series / Film values, Withdrawn Screenings, ingestion ports (`ProgrammeSource`, `VenueSource`, `RouteProvider`, repositories, `UnitOfWork`) and two use-cases (`ingest_venues`, `ingest_programme`). Driven adapters: `adapters/sqlalchemy/` (tables, migrations, repositories, unit of work), `adapters/filmfrasor/` (programme source over the legacy scraper), `adapters/yaml_files/venues.py` (venues and routes from the cinema config). The Typer CLI composes them in `festival-planner ingest …` and `festival-planner db upgrade`.

**Tech Stack:** Python 3.13, Pydantic 2 (domain values), SQLAlchemy 2.x (2.1.6 at time of writing), Alembic 1.x (1.20.1), SQLite, Typer, pytest. Tooling via `mise` + `uv`; version control is **jj**.

**Spec:** `docs/superpowers/specs/2026-10-23-graphql-backend-design.md`, section *Persistence and ingestion* and roadmap step 2. Vocabulary: `GLOSSARY.md` (note **Withdrawn**). Decisions: `docs/adr/0001` (hexagonal), `0002` (SQLite first, portable to Postgres), `0005` (aware datetimes, Festival time zone).

## Global Constraints

- `src/festival_planner/domain/` imports only the stdlib and Pydantic. No SQLAlchemy, Alembic, httpx, OR-Tools or Typer.
- Use glossary terms in new code: Festival, Festival Series, Film, Programme Entry, Screening, Event, Venue, Route, Transport Mode, Withdrawn. The legacy `models.py` and YAML keep their old names (`Film` = a screening row, `cinema`); only adapters translate.
- Screening, Event, `SolveRequest.now` and `ScheduledScreening.arrival_time` are timezone-aware (`pydantic.AwareDatetime`); naive values are rejected. Stored as UTC; read back with `tzinfo=UTC`.
- A Festival has an IANA `time_zone`; date ranges (Festival dates, Preferences' `start_date`/`end_date`) are festival-local dates.
- Ids are opaque strings; new ones are `str(uuid.uuid4())`, generated by the ingestion use-cases via an injectable `new_id` callable. Natural keys: Festival `slug`; Festival Series `slug`; Venue `name`; Programme Entry `(festival, source_key)`; Screening `(programme_entry_id, venue_id, start_time)`.
- Screenings missing from a re-ingestion become `withdrawn=True`; nothing is ever deleted by ingestion.
- Default Transport Mode is `"walk+e-scooter"`; after venue ingestion it must cover every ordered pair of distinct Venues.
- Unknown venue names abort a programme ingestion (one transaction) and report every unknown name.
- Schema and queries stay dialect-neutral (ADR-0002): no JSON/array columns, no SQLite-only SQL. Constraint names come from the metadata naming convention.
- Tests apply migrations with Alembic (`migrate(engine)`), never `metadata.create_all`.
- Tests live next to code in `tests/` sub-packages, each with an empty `__init__.py`.
- Run tests with `mise exec -- uv run pytest -q`. Format only files you touched: `mise exec -- uv run ruff format <paths>`. The repo has pre-existing ruff findings; don't fix unrelated ones.
- Commit with `jj commit -m "<message>"`. Never `git commit`. Do not push. Commit messages have no trailers (no `Co-Authored-By`).

`domain/festival.py`:

```python
"""Festivals and the series that group them."""

import datetime
import zoneinfo
from typing import Self

from pydantic import model_validator

from .values import Slug, TimeZone, Value

FestivalId = str
FestivalSeriesId = str


class FestivalSeries(Value):
    """The recurring identity that groups Festivals across years."""

    id: FestivalSeriesId
    slug: Slug
    name: str


class Festival(Value):
    """A single edition of a film festival."""

    id: FestivalId
    slug: Slug
    name: str
    start_date: datetime.date
    end_date: datetime.date
    time_zone: TimeZone
    series_id: FestivalSeriesId | None = None

    @model_validator(mode="after")
    def _ends_after_it_starts(self) -> Self:
        if self.end_date < self.start_date:
            raise ValueError(f"Festival {self.slug!r} cannot end before it starts")
        return self

    def local_date(self, instant: datetime.datetime) -> datetime.date:
        """The festival-local calendar day of `instant`."""
        return instant.astimezone(zoneinfo.ZoneInfo(self.time_zone)).date()
```

`domain/ingestion.py` (Task 5 appends the use-cases to this module):

```python
"""Ingesting festival data from external sources.

Sources describe what they found in plain values (`Source*`); the use-cases
reconcile that with what is stored, keeping ids stable across re-ingestion.
"""

import datetime
from collections.abc import Iterable, Mapping
from types import TracebackType
from typing import Protocol, Self

from pydantic import AwareDatetime, Field, model_validator

from .festival import Festival, FestivalId, FestivalSeries
from .programme import (
    Event, Film, ProgrammeEntry, Screening, Venue, venue_name_key,
)
from .travel import Route, TransportMode
from .values import Slug, TimeZone, Value


# --- What sources report ---------------------------------------------------


class SourceSeries(Value):
    slug: Slug
    name: str


class SourceFestival(Value):
    """A Festival as a ProgrammeSource describes it. Missing dates are derived
    from the Screenings' festival-local days."""

    slug: Slug
    name: str
    time_zone: TimeZone
    start_date: datetime.date | None = None
    end_date: datetime.date | None = None
    series: SourceSeries | None = None


class SourceScreening(Value):
    venue_name: str
    """The name the source uses; resolved through Venue names and aliases."""
    start_time: AwareDatetime
    end_time: AwareDatetime
    auditorium: str | None = None
    ticket_url: str | None = None
    events: tuple[Event, ...] = ()

    @model_validator(mode="after")
    def _ends_after_it_starts(self) -> Self:
        if self.end_time < self.start_time:
            raise ValueError("A screening cannot end before it starts")
        return self


class SourceEntry(Value):
    source_key: str = Field(min_length=1)
    """Identifies the Programme Entry within its Festival across re-ingestion."""
    title: str
    year: int | None = None
    country: str | None = None
    url: str | None = None
    screenings: tuple[SourceScreening, ...] = ()


class SourceProgramme(Value):
    festival: SourceFestival
    entries: tuple[SourceEntry, ...]

    @model_validator(mode="after")
    def _source_keys_are_unique(self) -> Self:
        seen: set[str] = set()
        for entry in self.entries:
            if entry.source_key in seen:
                raise ValueError(f"Duplicate source key {entry.source_key!r}")
            seen.add(entry.source_key)
        return self


class SourceVenue(Value):
    name: str
    aliases: frozenset[str] = frozenset()


class SourceRoute(Value):
    """A Route between Venues identified by name or alias."""

    from_venue: str
    to_venue: str
    mode: TransportMode
    minutes: int = Field(ge=0)

class VenueDirectory:
    """Resolves the names sources use to Venues, by name or alias."""

    def __init__(self, venues: Iterable[Venue]):
        self._by_key: dict[str, Venue] = {}
        for venue in venues:
            for name in (venue.name, *venue.aliases):
                key = venue_name_key(name)
                other = self._by_key.setdefault(key, venue)
                if other.id != venue.id:
                    raise AmbiguousVenueNameError(key, (other.name, venue.name))

    def resolve(self, name: str) -> Venue | None:
        return self._by_key.get(venue_name_key(name))
```

```python
class UTCDateTime(TypeDecorator[datetime.datetime]):
    """Aware datetimes stored as naive UTC, read back with tzinfo=UTC."""

    impl = DateTime
    cache_ok = True

    def process_bind_param(self, value, dialect):
        if value is None:
            return None
        if value.tzinfo is None:
            raise ValueError(f"Refusing to store naive datetime {value!r}")
        return value.astimezone(datetime.UTC).replace(tzinfo=None)
```

```python
"""Locating, connecting to and migrating the database."""

import os
from pathlib import Path

from alembic import command
from alembic.config import Config
from sqlalchemy import Connection, Engine, create_engine, event

from ...path_providers import PathProvider, create_default_path_provider

DATABASE_URL_ENV = "FESTIVAL_PLANNER_DATABASE_URL"
MIGRATIONS = Path(__file__).parent / "migrations"


def resolve_database_url(
    explicit: str | None = None, path_provider: PathProvider | None = None
) -> str:
    """`explicit` (a URL or a file path), else $FESTIVAL_PLANNER_DATABASE_URL,
    else a SQLite file in the XDG data directory."""
    if explicit:
        return explicit if "://" in explicit else f"sqlite:///{Path(explicit).resolve()}"
    if from_env := os.environ.get(DATABASE_URL_ENV):
        return from_env
    data_home = (path_provider or create_default_path_provider()).get_data_home()
    data_home.mkdir(parents=True, exist_ok=True)
    return f"sqlite:///{data_home / 'festival-planner.db'}"


def create_engine_for(url: str) -> Engine:
    engine = create_engine(url)
    if engine.dialect.name == "sqlite":
        event.listen(engine, "connect", _enable_sqlite_foreign_keys)
    return engine


def _enable_sqlite_foreign_keys(dbapi_connection, _record) -> None:
    cursor = dbapi_connection.cursor()
    cursor.execute("PRAGMA foreign_keys=ON")
    cursor.close()


def alembic_config(connection: Connection | None = None) -> Config:
    config = Config()
    config.set_main_option("script_location", str(MIGRATIONS))
    if connection is not None:
        config.attributes["connection"] = connection
    return config


def migrate(engine: Engine, revision: str = "head") -> None:
    """Bring the schema up to `revision`."""
    with engine.begin() as connection:
        command.upgrade(alembic_config(connection), revision)
```

```python
    def __init__(self):

        self.festivals: dict[str, Festival] = {}
        self.venues: dict[str, Venue] = {}
        self.routes: list[Route] = []

class InMemoryUnitOfWork:
    def __init__(self):
        self.stored = _State()
        self.committed = False

    def __enter__(self):
        self._work = copy.deepcopy(self.stored)
        self.festivals = _Festivals(self._work)
        self.venues = _Venues(self._work)
        self.routes = _Routes(self._work)
        self.films = _Films(self._work)
        self.programme = _Programme(self._work)
        return self

    def __exit__(self, *exc):
        del self._work

    def commit(self):
        self.stored = copy.deepcopy(self._work)
        self.committed = True
```

```python
import uuid
from collections.abc import Callable

from .programme import title_key
from .travel import DEFAULT_TRANSPORT_MODE


def new_id() -> str:
    return str(uuid.uuid4())


def ingest_venues(
    uow: UnitOfWork,
    venue_source: VenueSource,
    route_provider: RouteProvider,
    *,
    default_mode: TransportMode = DEFAULT_TRANSPORT_MODE,
    new_id: Callable[[], str] = new_id,
) -> VenueIngestion:
    """Create or update Venues (matched by name), then replace all Routes.

    Every ordered pair of distinct Venues needs a Route in `default_mode`.
    """
    report = VenueIngestion()
    with uow:
        existing = {venue_name_key(v.name): v for v in uow.venues.all()}
        for source in venue_source.venues():
            old = existing.get(venue_name_key(source.name))
            venue = Venue(id=old.id if old else new_id(), name=source.name, aliases=source.aliases)
            if venue != old:
                uow.venues.save(venue)
                existing[venue_name_key(venue.name)] = venue
                field = "venues_updated" if old else "venues_created"
                report = report.model_copy(update={field: getattr(report, field) + 1})
        venues = tuple(existing.values())
        directory = VenueDirectory(venues)
        source_routes = route_provider.routes(venues)
        unknown = [n for r in source_routes for n in (r.from_venue, r.to_venue)
                   if directory.resolve(n) is None]
        if unknown:
            raise UnknownVenuesError(unknown)
        routes = {
            (a.id, b.id, r.mode): Route(from_venue_id=a.id, to_venue_id=b.id, mode=r.mode, minutes=r.minutes)
            for r in source_routes
            if (a := directory.resolve(r.from_venue)) and (b := directory.resolve(r.to_venue)) and a.id != b.id
        }
        missing = [(a.name, b.name) for a in venues for b in venues
                   if a.id != b.id and (a.id, b.id, default_mode) not in routes]
        if missing:
            raise IncompleteRoutesError(default_mode, missing)
        uow.routes.replace_all(routes.values())
        uow.commit()
    return report.model_copy(update={"routes": len(routes)})


def ingest_programme(
    uow: UnitOfWork, source: ProgrammeSource, *, new_id: Callable[[], str] = new_id
) -> ProgrammeIngestion:
    """Store a Festival's programme, keeping ids stable across re-ingestion.

    Programme Entries are matched by source key, Screenings by (Programme
    Entry, Venue, start time). Screenings no longer in the source become
    Withdrawn. Films are matched by normalised title and year.
    """
    programme = source.fetch()
    counts: dict[str, int] = dict.fromkeys(
        ("films_created", "entries_created", "entries_updated", "screenings_created",
         "screenings_updated", "screenings_withdrawn"), 0)
    with uow:
        directory = VenueDirectory(uow.venues.all())
        unknown = [s.venue_name for e in programme.entries for s in e.screenings
                   if directory.resolve(s.venue_name) is None]
        if unknown:
            raise UnknownVenuesError(unknown)
        festival = _store_festival(uow, programme, new_id)

        def film_for(entry: SourceEntry) -> str:
            if entry.year is not None and (film := uow.films.find(entry.title, entry.year)):
                return film.id
            film = Film(id=new_id(), title=entry.title, year=entry.year)
            uow.films.save(film)
            counts["films_created"] += 1
            return film.id

        stored_entries = uow.programme.entries(festival.id)
        stored_screenings = {
            (s.programme_entry_id, s.venue_id, s.start_time): s
            for s in uow.programme.screenings(festival.id)
        }
        current: set[str] = set()
        for source_entry in programme.entries:
            old = stored_entries.get(source_entry.source_key)
            same_work = old is not None and (title_key(old.title), old.year) == (
                title_key(source_entry.title), source_entry.year)
            entry = ProgrammeEntry(
                id=old.id if old else new_id(),
                film_id=old.film_id if same_work else film_for(source_entry),
                title=source_entry.title, year=source_entry.year,
                country=source_entry.country, url=source_entry.url,
            )
            if entry != old:
                uow.programme.save_entry(festival.id, source_entry.source_key, entry)
                counts["entries_updated" if old else "entries_created"] += 1
            for s in source_entry.screenings:
                venue = directory.resolve(s.venue_name)
                key = (entry.id, venue.id, s.start_time)
                if key in current:
                    continue
                current.add(key)
                previous = stored_screenings.get(key)
                screening = Screening(
                    id=previous.id if previous else new_id(),
                    programme_entry_id=entry.id, venue_id=venue.id,
                    start_time=s.start_time, end_time=s.end_time,
                    auditorium=s.auditorium, ticket_url=s.ticket_url, events=s.events,
                )
                if screening != previous:
                    uow.programme.save_screening(screening)
                    counts["screenings_updated" if previous else "screenings_created"] += 1
        for key, screening in stored_screenings.items():
            if key not in current and not screening.withdrawn:
                uow.programme.save_screening(screening.model_copy(update={"withdrawn": True}))
                counts["screenings_withdrawn"] += 1
        uow.commit()
    return ProgrammeIngestion(festival_slug=festival.slug, **counts)


def _store_festival(uow: UnitOfWork, programme: SourceProgramme, new_id: Callable[[], str]) -> Festival:
    described = programme.festival
    series_id = None
    if described.series:
        old_series = uow.festivals.series_by_slug(described.series.slug)
        series = FestivalSeries(id=old_series.id if old_series else new_id(),
                                slug=described.series.slug, name=described.series.name)
        if series != old_series:
            uow.festivals.save_series(series)
        series_id = series.id
    zone = zoneinfo.ZoneInfo(described.time_zone)
    days = sorted(s.start_time.astimezone(zone).date()
                  for e in programme.entries for s in e.screenings)
    start = described.start_date or (days[0] if days else None)
    end = described.end_date or (days[-1] if days else None)
    if start is None or end is None:
        raise IngestionError(f"Cannot tell when {described.slug!r} takes place: no dates and no screenings")
    old = uow.festivals.by_slug(described.slug)
    festival = Festival(id=old.id if old else new_id(), slug=described.slug, name=described.name,
                        start_date=start, end_date=end, time_zone=described.time_zone,
                        series_id=series_id)
    if festival != old:
        uow.festivals.save(festival)
    return festival
```

```python
"""The UnitOfWork port over one SQLAlchemy session."""

from sqlalchemy import Engine
from sqlalchemy.orm import Session, sessionmaker

from .repositories import (
    SqlAlchemyFestivalRepository, SqlAlchemyFilmRepository, SqlAlchemyProgrammeRepository,
    SqlAlchemyRouteRepository, SqlAlchemyVenueRepository,
)


class SqlAlchemyUnitOfWork:
    def __init__(self, engine: Engine):
        self._sessions = sessionmaker(engine, expire_on_commit=False)

    def __enter__(self):
        self._session: Session = self._sessions()
        self.festivals = SqlAlchemyFestivalRepository(self._session)
        self.venues = SqlAlchemyVenueRepository(self._session)
        self.routes = SqlAlchemyRouteRepository(self._session)
        self.films = SqlAlchemyFilmRepository(self._session)
        self.programme = SqlAlchemyProgrammeRepository(self._session)
        return self

    def __exit__(self, *exc):
        self._session.rollback()
        self._session.close()

    def commit(self) -> None:
        self._session.commit()
```

`adapters/sqlalchemy/repositories.py`: each repository maps rows ↔ domain values with private `_to_domain` / `_apply` functions. Upserts are `row = session.get(Row, id)`, then create-and-add or assign attributes. Key points:

```python
class SqlAlchemyFilmRepository:
    def __init__(self, session: Session):
        self._session = session

    def find(self, title: str, year: int) -> Film | None:
        row = self._session.scalars(
            select(FilmRow)
            .where(FilmRow.match_key == title_key(title), FilmRow.year == year)
            .order_by(FilmRow.id)
            .limit(1)
        ).first()
        return None if row is None else Film(id=row.id, title=row.title, year=row.year)

    def save(self, film: Film) -> None:
        row = self._session.get(FilmRow, film.id) or FilmRow(id=film.id)
        row.title, row.year, row.match_key = film.title, film.year, title_key(film.title)
        self._session.add(row)
```

- `SqlAlchemyVenueRepository.save`: set `row.name` and `row.aliases = [VenueAliasRow(alias=a) for a in sorted(venue.aliases)]` (delete-orphan removes the old ones); `all()` orders by name.
- `SqlAlchemyRouteRepository.replace_all`: `session.execute(delete(RouteRow))`, then `add_all`; `all()` orders by (from, to, mode).
- `SqlAlchemyProgrammeRepository.entries(festival_id)`: `{row.source_key: entry}`; `save_entry` sets `festival_id`, `source_key` and the entry fields; `screenings(festival_id)` joins `ScreeningRow` to `ProgrammeEntryRow` on `festival_id`, ordered by `(start_time, id)`; `save_screening` sets every field and replaces `row.events` with `ScreeningEventRow(position=i, description=…, start_time=…, end_time=…)` in tuple order. Mapping back builds `Event`s from `row.events` (ordered by position).
- Call `self._session.flush()` at the end of every `save*`/`replace_all`, so constraint violations surface at the call and later queries in the same unit of work see the rows.

```python
"""Filmfrasor (Films from the South) as a ProgrammeSource, over the legacy scraper."""

import zoneinfo
from collections.abc import Iterable, Sequence
from pathlib import Path
from urllib.parse import urlsplit

from ...domain.ingestion import (
    SourceEntry, SourceFestival, SourceProgramme, SourceScreening, SourceSeries,
)
from ...domain.programme import Event, title_key
from ...models import Film
from ...scrapers.filmfrasor import FilmfrasorScraper

FESTIVAL_TIME_ZONE = "Europe/Oslo"
LANGUAGES = frozenset({"no", "en"})
SERIES = SourceSeries(slug="films-from-the-south", name="Films from the South")


class FilmfrasorProgrammeSource:
    def __init__(self, year: int, *, known_venue_names: Iterable[str],
                 cache_dir: Path | None = None, force_refresh: bool = False):
        self._year = year
        self._scraper = FilmfrasorScraper(cache_dir=cache_dir, year=year,
                                          force_refresh=force_refresh,
                                          known_venue_names=known_venue_names)

    def fetch(self) -> SourceProgramme:
        return programme_from_films(self._scraper.scrape().films, self._year)


def programme_from_films(films: Sequence[Film], year: int) -> SourceProgramme:
    zone = zoneinfo.ZoneInfo(FESTIVAL_TIME_ZONE)
    rows_by_key: dict[str, list[Film]] = {}
    for film in films:
        rows_by_key.setdefault(_source_key(film), []).append(film)
    return SourceProgramme(
        festival=SourceFestival(slug=f"films-from-the-south-{year}",
                                name=f"Films from the South {year}",
                                time_zone=FESTIVAL_TIME_ZONE, series=SERIES),
        entries=tuple(_entry(key, rows, zone) for key, rows in rows_by_key.items()),
    )


def _source_key(film: Film) -> str:
    """The film page's path without its language prefix, e.g. "film/fallen-leaves"."""
    if not film.url:
        return f"title:{title_key(film.title)}"
    parts = [p for p in urlsplit(film.url).path.split("/") if p]
    if parts and parts[0] in LANGUAGES:
        parts = parts[1:]
    return "/".join(parts)


def _entry(key: str, rows: list[Film], zone: zoneinfo.ZoneInfo) -> SourceEntry:
    first = rows[0]
    return SourceEntry(
        source_key=key, title=first.title, year=first.year, country=first.country, url=first.url,
        screenings=tuple(
            SourceScreening(
                venue_name=r.cinema,
                start_time=r.start_time.replace(tzinfo=zone),
                end_time=r.end_time.replace(tzinfo=zone),
                auditorium=r.auditorium, ticket_url=r.ticket_url,
                events=(Event(description=r.special_notes),) if r.special_notes else (),
            )
            for r in rows
        ),
    )
```

```python
"""Venues and Routes from the legacy cinema configuration."""

from ...domain.ingestion import SourceRoute, SourceVenue
from ...domain.programme import Venue
from ...domain.travel import DEFAULT_TRANSPORT_MODE, TransportMode
from ...models import CinemaConfig


class CinemaConfigVenues:
    """VenueSource and RouteProvider over `cinemas:` in config.yaml.

    Travel times apply in both directions unless the reverse is configured.
    """

    def __init__(self, cinemas: CinemaConfig, mode: TransportMode = DEFAULT_TRANSPORT_MODE):
        self._cinemas = cinemas
        self._mode = mode

    def venues(self) -> tuple[SourceVenue, ...]:
        aliases = self._cinemas.cinema_aliases
        names = dict.fromkeys([*aliases, *sorted(self._cinemas.get_valid_cinemas())])
        return tuple(SourceVenue(name=n, aliases=frozenset(aliases.get(n, ()))) for n in names)

    def routes(self, venues: tuple[Venue, ...]) -> tuple[SourceRoute, ...]:
        minutes = {(t.from_cinema, t.to_cinema): t.minutes
                   for t in self._cinemas.travel_times if t.from_cinema != t.to_cinema}
        for (a, b), m in list(minutes.items()):
            minutes.setdefault((b, a), m)
        return tuple(SourceRoute(from_venue=a, to_venue=b, mode=self._mode, minutes=m)
                     for (a, b), m in minutes.items())
```
